| Latest         | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to the project maintainers rather than creating a public GitHub issue.

Please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any screenshots or relevant logs, if applicable

The project maintainers will review the report and take appropriate action.

We aim to acknowledge security reports within **7 days** and will provide updates as the issue is investigated.

Please do not publicly disclose the vulnerability until the maintainers have had an opportunity to address it.

Thank you for helping us keep the SIH2026 project secure.
